# Advanced Public-Figure Consensus Matching Design

The owner-supplied implementation specification is accepted as the target design and is refined by the critical-lane artifacts under `docs/features/advanced-public-figure-consensus-matching/`.

The architecture preserves the extraction-only image boundary, builds bounded qualitative matching profiles, retrieves reviewed entity-ID candidates through deterministic text lanes, runs configured text participants against one shortlist, critiques structured evidence, calculates backend-authoritative median consensus scores, and enriches only final entity IDs through allowlisted public-data adapters.

The public endpoint remains compatible and all new behavior is default-off. Frontend additions remain inside the game module, use optional verified enrichment only, isolate mixed-direction values semantically, and provide a keyboard-accessible details dialog shared by live and temporary-share results.

Security failures fail closed at source validation and fail soft at optional enrichment. No arbitrary crawler, AI-controlled URL, personal-data cache, provider disclosure, production candidate special case, or public-image matching path exists.
