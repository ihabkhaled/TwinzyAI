# 03 — Product Requirements

- Every reviewed locale has a canonical public URL, reciprocal hreflang, and correct first response
  `lang`/`dir`; legacy public URLs permanently redirect to English.
- Sitemap index and bounded localized topic feeds include only reviewed editorial routes.
- Contact composes an email to a validated configured address and sends/stores nothing in Twinzy.
- Hero and supporting sections explain value, privacy, safety, limits, and the primary game action.
- Preview/local deployments remain noindex; shares and payment callbacks remain excluded.
