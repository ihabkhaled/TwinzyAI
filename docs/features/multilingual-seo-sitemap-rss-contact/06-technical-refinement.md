# 06 — Technical Refinement

Reuse the existing cookie-loaded dictionaries and unprefixed App Router owners. The request proxy
validates a leading locale, forwards it as a trusted internal header, rewrites to the existing route,
and redirects legacy public routes. Navigation builders prefix the active locale. SEO helpers own
canonical/hreflang; focused XML helpers escape and strip invalid controls. Contact uses a bounded
Zod model and `mailto:` only—no API, database, analytics, or third-party form processor.
