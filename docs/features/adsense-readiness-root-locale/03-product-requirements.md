# 03 — Product Requirements

1. Root English homepage returns 200 without redirect; explicit locale roots remain usable.
2. Locale changes communicate progress accessibly until navigation completes.
3. `ads.txt` is exact, plain text, and unredirected; robots and sitemap remain valid.
4. Canonical/hreflang rules avoid duplicate English-home indexing.
5. About, FAQ, Help, Privacy, Terms, How It Works, and AI Safety remain server-rendered and crawlable.
6. Content is useful and product-specific, never SEO spam.
